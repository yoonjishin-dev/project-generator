# 할 일 관리 서비스 기획서 (PRD)

> project-generator 템플릿 `spring-boot` v1.0.0로 생성된 문서입니다.

## 개요

개인 사용자가 할 일을 등록하고 카테고리별로 분류해 완료 여부와 마감일을 관리하는 서비스입니다.

## 목표

- 할 일을 빠르게 등록하고 한눈에 확인한다
- 완료 여부와 마감일로 할 일의 진행 상황을 관리한다
- 카테고리로 할 일을 분류한다

## 대상 사용자

| 사용자 | 설명 |
|---|---|
| 개인 사용자 | 업무와 개인 생활의 할 일을 한곳에서 관리하려는 사람 |

## 기능 요구사항

| ID | 기능 | 우선순위 | 설명 |
|---|---|---|---|
| F-001 | 할 일 등록 | MUST | 제목, 메모, 마감일을 입력해 할 일을 등록한다. |
| F-002 | 할 일 목록 조회 | MUST | 등록된 할 일 전체를 목록으로 본다. |
| F-003 | 할 일 수정 | MUST | 할 일의 제목, 메모, 마감일, 카테고리를 수정하고 완료 여부를 체크한다. |
| F-004 | 할 일 삭제 | MUST | 할 일을 삭제한다. |
| F-005 | 카테고리 관리 | SHOULD | 카테고리를 추가하고 삭제하며 목록을 본다. |
| F-006 | 할 일 카테고리 분류 | SHOULD | 할 일을 등록하거나 수정할 때 카테고리를 하나 지정한다. |

## 완료 조건

### F-001 할 일 등록

- [ ] 제목 없이 등록하면 오류가 표시된다
- [ ] 메모와 마감일은 입력하지 않아도 등록된다

### F-002 할 일 목록 조회

- [ ] 목록에 제목, 마감일, 완료 여부, 카테고리가 보인다

### F-003 할 일 수정

- [ ] 수정한 내용이 목록에 바로 반영된다
- [ ] 완료 체크와 해제를 할 수 있다

### F-004 할 일 삭제

- [ ] 삭제한 할 일은 목록에서 사라진다

### F-005 카테고리 관리

- [ ] 같은 이름의 카테고리는 두 번 만들 수 없다
- [ ] 카테고리 목록을 볼 수 있다

### F-006 할 일 카테고리 분류

- [ ] 카테고리를 지정하지 않은 할 일도 등록할 수 있다
- [ ] 없는 카테고리를 지정하면 오류가 표시된다
